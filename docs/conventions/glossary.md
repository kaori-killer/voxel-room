# 용어

코드·UI·커밋 메시지에서 같은 말을 쓴다.

| 쓰지 않는 말 | 쓰는 말 |
| --- | --- |
| 화주 | 셀러 |
| 센터 | 창고 |

## 이 프로젝트의 말

| 말 | 뜻 |
| --- | --- |
| 오브제 | 사진을 깎아 만든 복셀 덩어리 하나 |
| 보관함 | 만든 오브제를 담아 두는 목록. 속성은 여기에 붙는다 |
| 꺼내기 | 보관함의 오브제를 방에 놓는 것. 같은 오브제를 여러 개 꺼낼 수 있다 |
| 배치 | 방에 놓인 개체 하나 (`PlacedObjectType`) |
| 속성 | 오브제에 붙는 기능 — 캐릭터·음악재생·전등·피아노 |
| 방 | 바닥 격자와 네 벽, 그 안의 배치 전부 |
