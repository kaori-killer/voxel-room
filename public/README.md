# public/

정적 파일 자리. `/파일명` 으로 그대로 서빙된다.

## 메인 화면 데모 영상 (필요)

랜딩(`app/page.tsx`)이 아래 두 파일을 참조한다. 넣기 전까지는 자리만 잡힌 빈 박스로 보인다.

| 파일 | 쓰임 | 권장 |
| --- | --- | --- |
| `demo.mp4` | 사용 모습 데모 (무음·자동재생·반복) | 16:10 비율, 10초 내외, H.264 mp4, 소리 없이도 이해되게 |
| `demo-poster.jpg` | 영상 로드 전/재생 전 썸네일 | 영상 첫 프레임 |

- 자동재생을 위해 **무음(muted)** 이어야 한다. 소리는 넣지 않는다.
- 용량은 몇 MB 이내로 줄인다 (첫 화면 로딩에 바로 영향).
