# 복셀 공방 — my voxel room

그림 한 장을 올리면 픽셀을 정육면체로 쌓아 올려 복셀 3D 오브제로 깎고,
동물의숲 같은 방에 꺼내 놓고 꾸미는 도구입니다.
변환부터 저장까지 전부 브라우저 안에서 끝나고, 서버로 이미지를 보내지 않습니다.

## 무엇을 할 수 있나

**오브제 만들기** — 그림을 올리면(드래그·붙여넣기도 됩니다) 변환 스튜디오가 열립니다.

- **격자 해상도** 24–96칸. 한 칸이 복셀 하나가 됩니다.
- **두께** 2–24
- **입체 방식**
  - `부풀리기` 실루엣 안쪽으로 갈수록 두꺼워집니다. 캐릭터·손그림에 가장 잘 맞습니다.
  - `판` 일정한 두께로 밀어냅니다. 로고·아이콘용.
  - `릴리프` 밝은 부분이 튀어나옵니다. 음영이 있는 그림용.
- **배경 지우기** 테두리에서 시작하는 flood fill 이라 그림 안쪽의 흰색은 남습니다.

**방 꾸미기** — 만든 오브제는 보관함에 담기고, 눌러서 몇 개든 꺼낼 수 있습니다.

| 조작 | 하는 일 |
| --- | --- |
| 끌기 | 바닥 격자에 반 칸 단위로 찰칵 붙여 옮기기 |
| 빈 곳 끌기 | 시점 돌리기 |
| 휠 | 확대 (오브제 위에서는 크기 조절) |
| `R` | 45도 회전 |
| `Del` | 치우기 |

다른 오브제 위에 정확히 떨어뜨리면 그 위에 올라갑니다. 방 크기 3단계와
바닥·벽 팔레트 4종을 고를 수 있고, 카메라를 가로막는 앞쪽 벽은 자동으로 감춰집니다.

**속성** — 보관함 항목에 기능을 붙입니다. 같은 오브제를 여러 개 꺼내면 모두 같은 속성을 갖습니다.

- **캐릭터** — `WASD` 걷기, `Space` 점프, `Z` 앉기. 발 디딜 때마다 위아래로 눌리고
  좌우로 흔들리며 진행 방향으로 기울어집니다. 이동은 카메라 기준입니다.
  그림을 밀어낸 오브제라 옆을 보면 얇으므로, 늘 카메라 쪽을 보되 가는 방향으로만
  최대 54도 트는 3/4 자세를 유지합니다. 다른 오브제 위로 점프해 올라가고, 턱에서는 떨어집니다.
- **음악재생** — 선택하면 플레이리스트가 열립니다. 음악 파일을 넣고 재생하면
  선택을 풀어도 배경으로 계속 흐릅니다. 재생 중인 오브제는 리듬 타듯 들썩입니다.

## 저장

- **방과 보관함** — `localStorage`. 오브제는 격자 해상도 PNG 마스크로만 보관해서
  오브제 5개 + 배치 7개가 10KB 남짓입니다.
- **음악 파일** — `IndexedDB`. 새로고침해도 플레이리스트가 남습니다.
- **다른 기기로 옮기기** — `방 내보내기` 로 json 을 받아 `불러오기` 하면 됩니다.

둘 다 브라우저 안에만 있습니다. 시크릿 창이나 사이트 데이터를 지우면 사라집니다.

## 한계

그림의 앞모습을 두께로 밀어낸 복셀이라, 뒤통수까지 상상해 주는 진짜 3D 재구성은 아닙니다.
옆에서 보면 앞뒤가 같은 모양입니다. 배경이 단색이고 윤곽이 분명한 그림일수록 결과가 깨끗합니다.

## 구조

```
index.html            빌드 결과 — Vercel 이 이 파일 하나를 서빙합니다
build.py              src + vendor -> index.html
src/shell.html        마크업과 스타일 (three.js·앱 자리표시자 포함)
src/app.js            복셀 변환, 방, 캐릭터, 음악 플레이어
vendor/three.cjs.min.js   three r160 CommonJS 빌드를 최소화한 것
```

`index.html` 은 three.js 까지 전부 인라인된 단일 파일입니다. 외부 요청은
Google Fonts 하나뿐이라 파일을 그대로 열어도 동작합니다.

## 빌드

```bash
python3 build.py     # index.html 을 다시 만듭니다
```

빌드 결과를 커밋해 두므로 Vercel 에는 별도 빌드 단계가 없습니다.
`src/` 나 `vendor/` 를 고쳤다면 `build.py` 를 돌리고 `index.html` 을 함께 커밋하세요.

## 배포

Vercel 에서 이 저장소를 Import 하면 끝입니다. 프레임워크 없음(Other),
빌드 명령 없음, 출력 디렉터리는 저장소 루트입니다. 이후로는 `main` 에 푸시할 때마다
자동으로 배포됩니다.

로컬에서 확인하려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 만든 것

three.js(WebGL) · InstancedMesh · 100% 클라이언트 사이드.
빌드 도구도 프레임워크도 없고, 파이썬 스크립트 하나로 파일을 이어 붙입니다.
