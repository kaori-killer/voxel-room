# 복셀 공방

**사진 한 장을 3D 오브제로 깎아 내 방에 놓고 꾸밉니다.**

사진을 올리면 픽셀을 정육면체로 쌓아 입체로 만들고, 동물의숲 같은 방에
꺼내 놓습니다. 방마다 주소가 하나씩 생겨서 링크로 서로의 방을 볼 수 있습니다.

변환은 전부 브라우저 안에서 끝납니다. 사진은 어디로도 전송되지 않습니다.

---

## 시작하기

1. **내 방 만들기** — `/a7k2m9x4qp` 같은 주소가 하나 생깁니다.
2. **사진으로 오브제 만들기** (끌어다 놓거나 붙여넣기도 됩니다)
3. 미리보기를 보며 두께와 입체 방식을 고르고 **보관함에 넣고 방에 놓기**

보관함에 담긴 오브제는 몇 번이든 다시 꺼낼 수 있습니다.
링크를 보내면 다른 사람은 **구경만** 할 수 있습니다 — 고치는 건 만든 사람만.

---

## 방에서 할 수 있는 것

| | |
| --- | --- |
| 끌기 | 바닥 격자에 반 칸 단위로 찰칵 |
| 빈 곳 끌기 | 시점 돌리기 |
| 휠 · 두 손가락 | 확대 (오브제 위에서는 크기 조절) |
| `R` | 45도 회전 |
| `Del` | 치우기 |

다른 오브제 **위에 정확히** 떨어뜨리면 그 위에 올라갑니다.

---

## 속성 — 오브제에 기능 붙이기

속성은 보관함 항목에 붙습니다. 같은 오브제를 여러 개 꺼내면 모두 같은 기능을 갖습니다.

| 속성 | 하는 일 |
| --- | --- |
| 🚶 캐릭터 | `WASD` 걷기 · `Space` 점프 · `Z` 앉기 |
| 💡 전등 | 불 껐다 켜기, 밝기와 불빛 색 |
| 🎹 피아노 | 다가가서 연주 — 화면 건반을 키보드로 |
| 🎵 음악재생 | 음악 파일을 넣어 배경으로 재생 |

캐릭터로 오브제 가까이 가면 말풍선이 뜹니다. **`E`** 를 누르거나 말풍선을 눌러서 씁니다.
(`A` 는 왼쪽으로 걷는 키라 상호작용은 `E` 입니다.)

---

## 알아 두면 좋은 것

사진의 **앞모습을 두께로 밀어낸** 복셀입니다. 뒤통수까지 만들어 주는
진짜 3D 재구성은 아니라서, 옆에서 보면 앞뒤가 같은 모양입니다.

**배경이 단색이고 윤곽이 분명한 사진** 일수록 깨끗하게 나옵니다.
잘 안 되면 스튜디오에서 *배경 판정 민감도* 를 올리거나 내려 보세요.

음악 파일은 브라우저(IndexedDB)에만 남습니다. 방을 공유해도 음악은 따라가지 않습니다.

## 개발

```bash
npm install
npm run dev       # http://localhost:3000
npm run verify    # lint + typecheck + 단위·통합 테스트
npm run test:e2e  # Playwright
```

환경변수 없이도 뜹니다 — 방이 서버에 저장되지 않고 공유·채팅만 꺼집니다.
설정은 [docs/setup/environment.md](docs/setup/environment.md).

### 구조

```
app/          라우팅·서버 컴포넌트·route handler
src/engine/   three.js 렌더링 (React 를 모른다)
src/audio/    Web Audio (React 를 모른다)
src/domain/   순수 로직·타입·스키마
src/store/    방 저장소 어댑터 (Supabase / 메모리)
src/features/ 화면
docs/         컨벤션 — 코드·네이밍·커밋·리뷰 체크리스트
```

의존 방향은 한쪽이다: `app` → `features` → (`hooks`·`store`·`api`) → (`domain`·`engine`·`audio`·`lib`).
엔진과 오디오는 프레임워크를 모르고 테스트에서 단독으로 돈다.

규칙은 [docs/](docs/) 가 정하고, `eslint.config.mjs`·`tsconfig.json`·`.githooks/commit-msg` 가 강제한다.
커밋 훅은 클론 후 한 번 켠다: `git config core.hooksPath .githooks`

정적 단일 파일 버전(`main`)에서 옮겨 오는 중이다.

  채팅 API, 관리자 세션, GA4, SEO(메타·OG·sitemap·robots)

패널이 남아 있어 아직 `main` 을 대체하지 않는다.
