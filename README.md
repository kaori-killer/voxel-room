# 복셀 공방

**사진 한 장을 3D 오브제로 깎아 내 방에 놓고 꾸밉니다.**

사진을 올리면 픽셀을 정육면체로 쌓아 입체로 만들고, 동물의숲 같은 방에
꺼내 놓습니다. 캐릭터로 걸어 다니고, 전등을 켜고, 피아노를 칩니다.

변환은 전부 브라우저 안에서 끝납니다. 사진은 어디로도 전송되지 않습니다.

---

## 시작하기

1. **사진으로 오브제 만들기** 를 누릅니다. (끌어다 놓거나 붙여넣기도 됩니다)
2. 미리보기를 보며 두께와 입체 방식을 고릅니다.
3. **보관함에 넣고 방에 놓기** — 끝.

보관함에 담긴 오브제는 몇 번이든 다시 꺼낼 수 있습니다.

---

## 방에서 할 수 있는 것

| | |
| --- | --- |
| 끌기 | 바닥 격자에 반 칸 단위로 찰칵 |
| 빈 곳 끌기 | 시점 돌리기 |
| 휠 · 두 손가락 | 확대 (오브제 위에서는 크기 조절) |
| `R` | 45도 회전 |
| `Del` | 치우기 |

다른 오브제 **위에 정확히** 떨어뜨리면 그 위에 올라갑니다. 스탠드 위에 별, 같은 식으로요.

오른쪽 위 **방 꾸미기** 에서 방 크기 3단계와 바닥·벽 팔레트 4종을 고를 수 있습니다.

---

## 속성 — 오브제에 기능 붙이기

오브제를 고르고 조작 바의 **속성** 을 누르면 붙일 수 있습니다.
속성은 보관함 항목에 붙어서, 같은 오브제를 여러 개 꺼내면 모두 같은 기능을 갖습니다.

### 🚶 캐릭터

`WASD` 걷기 · `Space` 점프 · `Z` 앉기

발을 디딜 때마다 눌리고 좌우로 흔들립니다. 이동은 카메라 기준이라
시점을 돌려도 `W` 는 항상 화면 위쪽입니다. 다른 오브제 위로 점프해 올라갈 수도 있어요.

### 💡 전등

불을 껐다 켤 수 있습니다. 밝기와 불빛 색(노랑·하양·분홍·파랑)을 고르면
바닥과 벽에 빛이 번집니다. **밤하늘** 팔레트에서 특히 예쁩니다.

### 🎹 피아노

다가가서 **연주하기** — 화면에 건반이 뜨고 키보드로 칩니다.

`A S D F G H J K L` 흰건반 · `W E T Y U O P` 검은건반 · `Space` 페달

### 🎵 음악재생

음악 파일을 넣어 두면 배경으로 흐릅니다. 선택을 풀어도 계속 나와요.
재생 중인 오브제는 리듬을 탑니다.

---

## 다가가서 쓰기

캐릭터로 오브제 가까이 가면 말풍선이 뜹니다. **`E`** 를 누르거나 말풍선을 눌러서 씁니다.

- 피아노 → 연주하기
- 전등 → 불 켜기 / 끄기
- 스피커 → 음악 켜기 / 끄기

> `A` 는 왼쪽으로 걷는 키라 상호작용은 `E` 로 뒀습니다.

---

## 방은 어디에 저장되나요

**이 브라우저 안에만** 남습니다. 서버로 올라가지 않습니다.

- 방과 보관함 → `localStorage` (오브제 5개 + 배치 7개가 10KB 남짓)
- 음악 파일 → `IndexedDB` (새로고침해도 목록이 남습니다)

다른 기기로 옮기려면 **방 내보내기** 로 json 을 받아 **불러오기** 하세요.
시크릿 창이나 사이트 데이터 삭제 시에는 사라집니다.

---

## 알아 두면 좋은 것

사진의 **앞모습을 두께로 밀어낸** 복셀입니다. 뒤통수까지 만들어 주는
진짜 3D 재구성은 아니라서, 옆에서 보면 앞뒤가 같은 모양입니다.
그래서 캐릭터는 늘 카메라 쪽을 보되 가는 방향으로만 살짝 틉니다.

**배경이 단색이고 윤곽이 분명한 사진** 일수록 깨끗하게 나옵니다.
잘 안 되면 스튜디오에서 *배경 판정 민감도* 를 올리거나 내려 보세요.

<summary>개발자용 — 구조와 빌드</summary>

```
index.html                빌드 결과. Vercel 이 이 파일 하나를 서빙한다
build.py                  src + vendor → index.html
src/shell.html            마크업과 스타일
src/app.js                복셀 변환, 방, 캐릭터, 전등, 피아노, 음악
vendor/three.cjs.min.js   three r160 CommonJS 빌드 (UMD 빌드는 콘솔 경고를 남긴다)
```

`index.html` 은 three.js 까지 인라인된 단일 파일이다. 외부 요청은 Google Fonts 하나뿐이라
파일을 그대로 열어도 동작한다.

```bash
python3 build.py            # index.html 다시 만들기
python3 -m http.server 8000 # 로컬에서 열기
```

빌드 결과를 커밋하므로 Vercel 에 별도 빌드 단계가 없다.
`src/` 나 `vendor/` 를 고쳤다면 `build.py` 를 돌리고 `index.html` 을 함께 커밋한다.

three.js(WebGL) · InstancedMesh · 100% 클라이언트 사이드. 프레임워크 없음.

</details>
